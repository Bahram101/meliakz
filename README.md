# Melia Kazakhstan

Сайт melia.kz — React 18 + Vite.

## Команды

| Команда           | Что делает                                                   |
| ----------------- | ------------------------------------------------------------ |
| `npm start`       | dev-сервер на http://localhost:3000 (доступен и по Wi-Fi)     |
| `npm run build`   | продакшен-сборка в папку `build/`                            |
| `npm run preview` | локальный просмотр собранной `build/`                        |
| `npm run lint`    | проверка кода ESLint                                         |
